# Rice_Flowering_Genes_haplotype_site

Preliminary (draft 2026-11-04, not validated): ∆DTF distributions of P vs NP accessions and 5-gene haplotype results (Hd1+Ehd1+Hd3a+RFT1 + OsATG8c / OsATG8b), with the SNP-selection method; SNP regression of ∆DTF over 44 genes; haplotypes from SNPs with p<0.05 (selection-aware permutation); single-gene haplotype analysis of all genes of zones 1–5 (OsATG8a highlighted). No accession names/IDs.

- `index.html` — results page
- `figures/` — ∆DTF histograms (PNG, PDF)
- `img/` — OsATG8c / OsATG8b haplotype boxplots
- `data/` — downloadable tables (xlsx, csv; `data/snp_regression/` for the SNP regression, `data/per_gene/` for the single-gene haplotypes)
