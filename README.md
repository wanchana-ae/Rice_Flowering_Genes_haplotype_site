# Rice_Flowering_Genes_haplotype_site

Preliminary (draft 2026-11-05, not validated): haplotype analyses of the flowering-time genes in 146 accessions (139 P + 7 NP without Hd1 deletion) with ∆DTF (sections 1-5) and with the flowering date in short day and long day (sections 6-9), and Manhattan/QQ plots of the GWAS (section 9). No accession names/IDs.

- `index.html` — results page (sections 6 and 7 include SD vs LD side-by-side plots, same y-axis, with plot/table downloads)
- `figures/`, `img/` — figures
- `data/` — downloadable tables (csv, xlsx)

Visual style: paper theme adapted from the design ideas and colour tokens of [Looseleaf](https://github.com/kevintngo/looseleaf) by Kevin Ngo (MIT licence); CSS only, no code or fonts copied.
